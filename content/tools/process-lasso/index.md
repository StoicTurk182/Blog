# Process Lasso

Process Lasso is an innovative system optimization and automation software that improves PC performance, responsiveness, and stability through process priority optimization, CPU affinity management, and proactive system monitoring.

## Overview
---

Process Lasso works in the background to optimize your system's process scheduling, ensuring that important applications get the CPU resources they need while preventing background processes from degrading system responsiveness. It's particularly effective for gamers, content creators, and power users who demand maximum system performance.

## Key Features
---

### Process Optimization
---
- **ProBalance® Technology**: Dynamically adjusts process priorities to maintain system responsiveness
- **CPU Affinity Management**: Assign specific processes to particular CPU cores
- **Priority Classes**: Fine-tune process priority levels for optimal performance
- **Instance Limiting**: Restrict how many instances of a process can run simultaneously

### Performance Monitoring
---
- **Real-time System Graphs**: Monitor CPU, RAM, and I/O usage
- **Process Statistics**: Detailed information about running processes
- **Performance Logging**: Track system performance over time
- **Threshold Alerts**: Get notified when system resources reach critical levels

### Automation & Rules
---
- **Persistent Settings**: Apply optimizations automatically on process launch
- **Power Plan Automation**: Switch power plans based on system activity
- **Instance Rules**: Control how applications launch and behave
- **Scheduled Actions**: Automate system maintenance tasks

### Gaming & Application Focus
---
- **Game Mode**: Automatically optimize system for gaming sessions
- **Application Responsiveness**: Ensure foreground applications remain responsive
- **Background Process Management**: Prevent background tasks from interrupting workflow
- **I/O Priority Management**: Optimize disk access for critical applications
