My 2025 Custom PC Build: Upper Mid-Range Powerhouse

hardware

AMD Ryzen 9 7900X and Radeon RX 9070 deliver exceptional performance under £2,000

System Overview

This system is my latest and most capable build to date. I engineered it for the upper mid-range tier, where it confidently tackles everything from gaming to intensive creative applications. Remarkably, the entire setup cost less than £2,000 as of this September and even surpasses the performance of my old 5950x, which has since been relegated to server duty for video production.

Complete Specifications:

CPU: AMD Ryzen 9 7900X

GPU: AMD Radeon RX 9070

Motherboard: MSI MAG X670E TOMAHAWK WIFI (MS-7E12)

Memory: 64GB CP32G64C40U5B.M8B3

Storage:

  • Samsung SSD 990 PRO with Heatsink 1TB
  • Samsung SSD 970 EVO Plus 250GB
  • WD_BLACK SN770 1TB

Power Supply: Antec SF850X 850W Power Supply 80+ Gold

Case: FRAME 4000D Modular Mid-Tower PC Case

Cooling: Thermalright Phantom Spirit 120 EVO

Peripherals:

  • Dual Monitor Setup
  • MAG 27CQ6F
  • PL2470H

Performance Assessment: Upper Mid-Range - I will add Linux benchmarks soon! I plan on getting more RAM and a better GPU but for minor dev work this is a great system.

Value Proposition: Exceptional performance-to-cost ratio, outperforming previous high-end systems while maintaining budget consciousness.

Build Philosophy

Why This Configuration Works

recommended

Strategic component selection for maximum performance per pound

Design Strategy:

  • Balanced Budget Allocation: Prioritized CPU and GPU while maintaining quality across all components
  • Future-Proof Foundation: AM5 platform with DDR5 memory ensures long-term upgrade path
  • Thermal Efficiency: High-performance air cooling maintains optimal temperatures without liquid complexity
  • Storage Tiering: Combination of high-speed NVMe drives for different workload requirements

Key Decisions:

  • AMD Ryzen 9 7900X for exceptional multi-threaded performance
  • Radeon RX 9070 for competitive gaming and creative workloads
  • 64GB RAM to handle demanding development environments
  • Multiple storage tiers for optimized workflow management

Future Upgrades

Planned Enhancements

update

RAM expansion and GPU upgrades on the horizon

Next Phase Upgrades:

  • Memory Expansion: Additional 64GB RAM for virtualized development environments
  • GPU Enhancement: Next-generation graphics card for improved rendering performance
  • Storage: Additional NVMe storage for project archives
  • Cooling: Potential upgrade to high-end air cooler or AIO solution

Timeline: Q1 2026 for initial upgrades, with further enhancements planned throughout the year.
